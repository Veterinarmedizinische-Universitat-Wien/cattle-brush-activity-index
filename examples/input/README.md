# Example input

Large video files are intentionally not stored in this GitHub repository.

For a local smoke test, place one representative video in this folder and set
`input_folder` in `src/config.py` to this directory. A file without a DVR or
recognised filename timestamp will be processed independently using relative
time beginning at `00:00:00`.

Study videos are planned for release through the university/institutional data
repository. Add the final data DOI/link to the main README when available.
