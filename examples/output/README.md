# Example output

Generated annotated videos, plots, and Excel reports can be written here during
local testing. Large generated videos are intentionally excluded from GitHub.

`rotation_summary_schema.csv` is a header-only example showing the columns of
the main rotation-interval report. It does **not** contain study results.

For the manuscript, a short annotated example output video can be supplied as
supplementary material (for example, Supplementary Video S1) rather than stored
in this repository.
